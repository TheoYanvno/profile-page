# Profile Page

**▶ [See it live](https://theoyanvno.github.io/profile-page/)**

A personal profile page built with plain HTML and CSS: a header with a menu, an About card with a picture, a list of what I'm learning, and an Email me button. It works on phones too.

## What it shows

- Headings, paragraphs, lists, links and images
- Semantic structure: `header`, `nav`, `main`, `section`, `footer`
- CSS selectors, colors and fonts
- The box model: padding, border, margin and rounded corners
- Flexbox for the header and menu, and `max-width` with `margin: 0 auto`
- A media query that stacks the header on narrow screens

## Run it

Open `index.html` in a browser, or use VS Code's Live Server.
